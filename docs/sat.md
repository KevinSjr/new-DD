# SAT no Daydreaming

## Formato conferido em 22/10/2026

O [SAT digital atual](https://satsuite.collegeboard.org/sat/whats-on-the-test/structure) tem Reading and Writing (54 questões, 64 minutos: dois módulos de 27 questões/32 minutos) e Math (44 questões, 70 minutos: dois módulos de 22 questões/35 minutos), com intervalo de 10 minutos. O segundo módulo de cada seção é adaptado ao desempenho no primeiro. A pontuação oficial não pode ser inferida diretamente de uma porcentagem de acertos.

Os arquivos fornecidos pelo usuário são as **versões não digitais/em papel** dos [SAT Practice Tests #4](https://satsuite.collegeboard.org/media/pdf/sat-practice-test-4-digital.pdf), [#5](https://satsuite.collegeboard.org/media/pdf/sat-practice-test-5-digital.pdf), [#6](https://satsuite.collegeboard.org/media/pdf/sat-practice-test-6-digital.pdf), [#7](https://satsuite.collegeboard.org/media/pdf/sat-practice-test-7-digital.pdf), [#8](https://satsuite.collegeboard.org/media/pdf/sat-practice-test-8-digital.pdf) e [#9](https://satsuite.collegeboard.org/media/pdf/sat-practice-test-9-digital.pdf), com suas explicações de respostas. Cada teste tem 33 questões em cada módulo de Reading and Writing (39 minutos por módulo) e 27 em cada módulo de Math (43 minutos por módulo). A plataforma identifica o modo exame como reprodução não adaptativa desse material; não o apresenta como SAT digital oficial.

- `/exames/sat` oferece escolha de modo. O desafio diário se divide em Reading and Writing e Mathematics, com cinco questões e três sóis independentes por área. Ambos misturam questões dos testes 4 a 9, sem criar um desafio próprio para cada teste. Os sóis renovam no dia seguinte, pelo horário de Brasília. A tentativa e o relatório não são salvos: recarregar reinicia.

A importação automatizada mantém o recorte visual original justamente porque a extração de texto perde parte dos elementos visuais; uma revisão humana item a item ainda é recomendada antes de disponibilização pública.

## Como executar

1. Configure o PostgreSQL em `.env.local` e rode `npm run db:migrate`.
2. Em um terminal, rode `npm run api:dev`; em outro, `npm run dev`.
3. Abra `http://localhost:5173/exames/sat`.
4. Para o CRUD, defina `ADMIN_USERNAME` e `ADMIN_PASSWORD_HASH` em `.env.local`. Gere o hash com `npm run admin:hash`, digitando a senha localmente (não a envie pelo chat nem a versione). Reinicie a API e abra `http://localhost:5173/admin/sat`.

O catálogo público não possui links externos nos cartões. URLs oficiais são mantidas nos dados e no painel de administração para rastreabilidade.

Para reconstruir a migração e os recortes a partir dos PDFs originais, instale `pymupdf` e `pillow` em um ambiente Python. Execute `python scripts/audit_sat_pdf.py <teste4.pdf> <explicacoes4.pdf> --build` para o nº 4, ou `python scripts/import_sat_practice_N.py <testeN.pdf> <explicacoesN.pdf>` para N = 5, 6, 7, 8 ou 9. A reconstrução substitui os arquivos gerados; ela não executa a migração no banco. Sem `--build`, o script nº 4 apenas audita numeração e gabaritos. As chaves nº 5 a nº 9 estão registradas nos respectivos scripts e conferidas contra as explicações fornecidas e os guias oficiais de pontuação.
